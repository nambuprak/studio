# **App Name**: RepoNavigator

## Core Features:

- Header Display: Display a header with the company name 'My Company' and the title 'Self Tutor'.
- Repository Selection: Render a select box listing available repositories, fetched from a configuration.
- Page Navigation: Present three navigation buttons: Create, Learn, and Edit, each linking to its respective page.

## Style Guidelines:

- Primary color: Dark Slate Blue (#483D8B) for a professional and intellectual feel, nodding to the educational aspect of the 'Self Tutor' title.
- Background color: Very light gray (#F0F0F0), a desaturated near-white for a clean and unobtrusive backdrop.
- Accent color: Lavender (#E6E6FA), an analogous color for interactive elements to highlight their functionality without overwhelming the primary color.
- Use a clean, sans-serif font for the header and body text to ensure readability and a modern look.
- Employ a grid-based layout for responsive design, ensuring the repository selection and navigation buttons are well-organized on various screen sizes.
- Subtle transition animations on button hover states to provide clear visual feedback to the user.
